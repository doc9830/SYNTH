# Changelog

Все значимые изменения проекта SYNTH. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-27

Первый публичный выпуск SYNTH (Synthetic Neural & Tool Hub).

### Добавлено
- **Универсальное подключение**: приложение работает с любым OpenAI-совместимым API.
  Мастер первого запуска из двух шагов — Base URL + API key, затем выбор модели для чата
  и (опционально) для изображений. Пресеты OpenAI, OpenRouter, RuAPI, DeepSeek, Groq,
  Mistral, Together, Ollama, LM Studio.
- **Стартовый экран** с объяснением возможностей вместо пустого чата, пока подключение не настроено.
- **Живой стриминг ответа**: текст печатается по мере генерации (раньше ответ появлялся целиком
  после завершения).
- **Мысли модели под катом**: блок «Думаю…» с таймером, автопрокруткой и авто-сворачиванием,
  когда начинается ответ; после завершения — «Размышления модели · 12 с».
- **Фазовые статусы** как в ChatGPT/Claude: «Готовлю ответ…», «Думаю…», «Ищу в интернете…»,
  «Читаю страницу по ссылке…», «Генерирую изображение…», «Пишу код…», «Отвечаю…».
- **Обновления из приложения**: проверка релизов GitHub (не чаще раза в 6 часов, с возможностью
  «Пропустить версию»), диалог «Что нового», загрузка APK с прогрессом и запуск системного
  установщика через локальный плагин `SynthUpdater`. В браузере — переход на страницу релиза.
- Отдельная вкладка «О программе» в настройках: версия, ссылка на релизы, кнопка проверки обновлений.
- Пресеты провайдеров в настройках API; подпись подключения (например, «OpenAI») в сайдбаре.

### Изменено
- **Ребрендинг**: приложение называется SYNTH, `applicationId` — `app.synth.hub`,
  новая иконка-«нейронный хаб» и сплэш-экраны (генератор `scripts/brand.mjs`).
- Провайдерский слой переименован в `src/providers/openai` (это OpenAI-совместимый протокол,
  а не привязка к конкретному шлюзу); заголовок авторизации для proxy-режима — `x-provider-key`.
- Сообщения об ошибках и подсказки стали провайдер-нейтральными.
- Backend-proxy: переменные `PROVIDER_BASE_URL`, `PROVIDER_API_KEY`, `PROVIDER_MODEL`
  (старые `RUAPI_*` поддерживаются для совместимости).
- Отрисовка стрима больше не зависит только от `requestAnimationFrame`: добавлен таймер-страховка
  (~8 обновлений в секунду), чтобы текст печатался и в фоновой вкладке/неактивном WebView.
- Генерация изображений по умолчанию выключена — включается выбором image-модели.

### Удалено
- `ReasoningBlock` — заменён на `ThinkingPanel` со статусами фаз и таймером.
